# Proyecto Jarvis-Son V1 para Dispostivos Android de Forma Local
Desarrollo de un asistente local de voz ligero que escuche una frase, la transcriba, genere una respuesta breve y la lea en voz alta.

## Integrantes

Andrés Saldarriaga Restrepo y Yuldainer Ospina Corrales

## Especificaciones del Dispositivo Android para el Proyecto - Samsung Galaxy A26

## Version Android
- Android 15 (Vanilla Ice Cream)

### Procesador
- Samsung Exynos 1280
- Arquitectura ARMv8.2-A
- 6xCortex-A55 y 2xCortex-A78

### RAM
- 8GB LPDDR4x (2.67 libres)

### GPU
- ARM Mali-G68 4 cores

### Almacenanmiento
- 256 GB y 135 GB disponibles
